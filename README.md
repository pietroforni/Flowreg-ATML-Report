
# FlowReg — Reinforcement Learning Reproducibility Study

University group project — Università della Svizzera italiana (USI).

Reproduction of FlowReg, a Neural ODE-based regularization
method for reinforcement learning, evaluated on MiniGrid
and Atari environments.

My individual contribution focused on Atari ablation
experiments, investigating regularization strength,
training stability, and action-conditioned latent dynamics.

**Authors:** Pietro Bernardo Maria Forni,
Luigi Tisci, Matteo Vitali.
